# U NOTE

**A modern Python-based text editor**

U NOTE is a modern desktop text editor built with Python and PyQt6.

## Features

- Modern interface
- Syntax highlighting
- Multiple programming language support
- Custom application icon

## Technologies

- Python
- PyQt6

## Installation

Install the required dependency:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python U_NOTE.py
```

Windows
